# Positivus Landing Page

Este projeto foi desenvolvido como parte de um **teste técnico para processo seletivo**, com o objetivo de reproduzir uma landing page a partir de um protótipo no Figma, mantendo fidelidade visual, organização de código e boas práticas de desenvolvimento.

## 🚀 Tecnologias utilizadas

- Next.js
- React
- Tailwind CSS

## 🎯 Objetivo

Implementar uma landing page moderna seguindo um design pré-definido no Figma, garantindo:

- Fidelidade ao layout original
- Responsividade
- Código limpo e organizado

## 🌐 Deploy

A aplicação foi publicada utilizando Vercel.

## 📌 Observações

- O foco principal foi a reprodução fiel do protótipo
- Pequenos ajustes podem ter sido feitos para melhorar responsividade e usabilidade
- O projeto não possui integração com backend, sendo exclusivamente frontend

---

Desenvolvido para fins de avaliação técnica.
